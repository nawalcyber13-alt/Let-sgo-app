Kebijakan Privasi

LetsGo APK memproses data konfigurasi yang kamu masukkan (URL situs, nama aplikasi, ikon, dan pengaturan tata letak) untuk membuat konfigurasi build aplikasi Android.

Data yang disimpan

Status kuota, status premium, dan riwayat build disimpan di perangkat/akun kamu sendiri agar tetap tersedia saat kamu membuka aplikasi kembali. Kami tidak menjual data ini ke pihak ketiga.

Berkas yang kamu unggah

Ikon atau berkas situs yang kamu unggah hanya digunakan untuk pratinjau konfigurasi build di dalam aplikasi ini.

Kontak

Ada pertanyaan seputar privasi? Hubungi co-founder melalui menu "Hubungi Co-founder".

Keamanan

Kode aktivasi premium diverifikasi menggunakan sidik hash, sehingga kode asli tidak pernah disimpan dalam bentuk teks biasa di dalam aplikasi.

Perlu diketahui: aplikasi ini berjalan sepenuhnya di sisi klien (browser). Untuk penggunaan produksi dengan banyak pengguna, verifikasi kode sebaiknya juga dilakukan lewat server agar lebih aman dari upaya rekayasa balik.

Catatan proses build

Tahap "Bangun APK" pada versi ini adalah simulasi antarmuka untuk menunjukkan alur build. Kompilasi APK Android yang sesungguhnya memerlukan layanan build terpisah (mis. Android SDK/Gradle di server) yang perlu dihubungkan pada versi produksi.

Tentang LetsGo APK

LetsGo APK membantu mengubah situs web (dari URL atau berkas lokal) menjadi konfigurasi aplikasi Android, lengkap dengan pengaturan tata letak, tema, dan fitur lanjutan.
